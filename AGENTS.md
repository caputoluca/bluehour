# Blue Hour — maintainer notes

One theme, one JSON, no build step (single variant → plain JSON, per the authoring brief in craft). Source of truth is `themes/blue-hour-color-theme.json`; `palette.json` names the roles.

- **Layout:** `package.json` (manifest, one `contributes.themes` entry) · `themes/` · `palette.json` (the vocabulary) · `samples/` (dev-host workspace, pins the theme) · `tools/colortool.py` (OKLCH / WCAG / APCA checker) · `tools/check.py` (drift check: palette ↔ theme ↔ README table ↔ token rule names) · `.vscode/launch.json` (F5).
- **Commands:** F5 or `cursor --extensionDevelopmentPath="$PWD" "$PWD/samples"` to look; `python3 tools/check.py` before a commit; `npx @vscode/vsce package` to build a `.vsix`; `cursor --install-extension <file>.vsix` to install.
- **Rules:** every colour is designed on the ladder and checked with the tool before it goes in — no eyeballed hex, no verbatim photo samples. Red only for errors and deletions. No italics. Keep the README's "Where this stands" line current; it is the pick-up point.
- **Vocabulary (decided 2026-09-28).** `palette.json` keys are the one set of names; the README ladder table's first column and the token rule names in the theme (`<what> — <key>[, note]`) follow them, and `tools/check.py` fails when the three drift. Neutrals by rung, extending Rosé Pine's `muted`/`subtle`/`text` (the reference ladder in `~/projects/craft/briefs/theme-colour-systems-2026.md`): `ground`, `raised`, `hairline`, `muted`, `comment`, `subtle`, `frame`, `text`, `bright`. Accents by colour: `blue`, `sky`, `peach`, `gold`, `red`, `green`, `magenta` — the last exists only for the ANSI slot, the room has no purple. State backgrounds at the blue-hour hue: `highlight_low`/`_mid`/`_high`. Terminal brights: `<base>_bright`. File order, which the table follows: neutrals and highlights by lightness, accents by family (cool pair, warm pair, then the status colours), brights in ANSI slot order. Why: three vocabularies named the same rungs, and the table had drifted eleven values behind the file (audited 2026-09-18).
